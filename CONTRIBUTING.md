# Contributing to Batchqlite

The rules are simple (for now).

Open an issue for discussion before undertaking substantial work.

Keep contributions small and tightly focused.

Don't use LLMs to write your code. You can use it for planning and analysis, which is how I use it. But every line of code should be hand-written (or good enough to fool me). An example Aider [configuration](aider.conf.yml.example) and [`AIDER.md`](AIDER.md) are included with instructions on how to use LLMs as the most expensive rubber duck humanity has ever created.

Bug reports should be descriptive, with clear steps to reproduce.

Be respectful. We're all volunteers here.
